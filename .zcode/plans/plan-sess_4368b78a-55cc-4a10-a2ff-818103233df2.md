# 安全审计结论

## 隐私:无泄露 ✅

- 无任何硬编码密钥:阿里云 AK/SK、ADMIN_TOKEN 全部经 `process.env` 注入;`.env.example` 全为占位符;仓库不存在 `.env` 实体文件
- **全部 145 个 git 历史提交已核查**:真实密钥从未进入历史(无 `LTAI` 命中,`ADMIN_TOKEN=` 历史命中均为占位符)
- 无选手/个人隐私数据(手机号、QQ、微信、身份证、邮箱全仓库零命中;players.js 仅为 UI 渲染)
- `deploy/` 无内嵌密钥:systemd 用 `EnvironmentFile=/etc/youshoubei.env` 外置,nginx/Caddy 示例只含证书路径

## 网络安全:基线良好,但存在 1 个高危漏洞,有改进空间 ⚠️

亮点(无需改动):`timingSafeEqual` 鉴权、魔数嗅探 + 5MB 限流上传、CSPRNG 舞台 ID、全站 CSP、输出转义纪律、无 CORS 放行、依赖树干净无已知 CVE。

问题清单(按严重度):

| 级别 | 问题 | 位置 |
|---|---|---|

# 改进计划

## P0 — 修复 null 字节崩溃 DoS(server.js)
1. `requestHandler` 中 `decodeURIComponent` 之后:若 pathname 含 `\0`,直接 `sendPlain(res, 400, 'Bad Request')` 返回
2. 兜底:`fs.readFile` 调用(`server.js:173`)包一层 try/catch,同步抛出时返回 404

## P1 — 收敛静态暴露面 + 大小写绕过(server.js)
1. 新增拒绝清单(与隐藏文件检查同层):路径段命中 `node_modules`、`test`、`scripts`、`deploy`、`docs`、`api`、`design-system`,或根级 `server.js`、`package.json`、`package-lock.json`、`bracket-model.js`、`.env.example` → 403
   - 拒绝比对用 `pathname.toLowerCase()`(同时修复 `/API/` 大小写绕过);`/api/` 前缀判断同样先小写化
   - 前端实际引用的根目录 JS(bracket/canvas-editor/canvas-model/common/deck-modal/home/library/players/theme-init)与 `vs-poster/` 不受影响
2. 冒烟测试新增断言:`/node_modules/ali-oss/package.json`、`/test/server-smoke.test.js`、`/server.js`、`/API/oss.js`、`/%00` 均不返回 200

## P1 — 安全响应头
1. `server.js`:`sendPlain`、`apiResponse`、静态下发三处统一追加 `X-Frame-Options: DENY`、`Referrer-Policy: strict-origin-when-cross-origin`、`Permissions-Policy: camera=(), microphone=(), geolocation=()`(抽成公共函数,meta CSP 表达不了 frame-ancestors)
2. `deploy/nginx.conf.example` 443 块加 `add_header Strict-Transport-Security "max-age=31536000" always;`
3. `deploy/Caddyfile.example` 加 `header Strict-Transport-Security "max-age=31536000"`

## P1 — ADMIN_TOKEN 迁出 localStorage(common.js)
1. `LS_ADMIN_TOKEN` 读写(`common.js:481-482,1850`)改用 `sessionStorage`
2. 启动加载时做一次性迁移:若旧 localStorage 键存在,复制到 sessionStorage 后删除旧键
3. 代价:管理员重开浏览器需重新输入口令(口令输入框已存在,可接受)

## P2 — API 错误信息收敛
- `api/data.js:24,58`、`api/upload.js:72`、`api/poster-stage.js:97,142`、`server.js:114`:500 响应改为固定文案 `"服务器内部错误"`,`error.message` 仅保留在服务端 `console.error`

## P3 — 前端纵深防御(可选,CSP 已兜底)
1. `vs-poster/js/poster.js:306,316`:image href 拼接前过白名单校验(参照 `common.js:120` 的 `safeUrl`);VSState 从 localStorage 加载时校验 color 匹配 `^#[0-9a-fA-F]{6}$`
2. `home.js:71`:改用 `common.js:129` 的 `cssUrl()`(会剥离引号)替代手工 `"url('" + safeUrl(url) + "')"` 拼接

## 验证
- `npm test` 全量通过(8 个测试文件),含 `server-smoke.test.js` 新增断言;手工 `curl http://localhost:PORT/%00` 返回 400 且进程存活
