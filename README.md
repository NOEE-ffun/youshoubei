# 8 人 BO3 双败淘汰赛制网站

这个网站服务一场 8 人 BO3 比赛，赛程和卡组各占一个页面。比分填完，晋级名单和最终名次自动更新，不需要手动安排下一轮。

## 页面

赛程页按标准双败淘汰赛排布，一共 14 场。胜者组四分之一决赛四场、半决赛两场、决赛一场；败者组第一轮两场、第二轮两场、半决赛一场、决赛一场，最后是总决赛。胜者组决赛的败者进入败者组决赛。总决赛结束后显示冠军、亚军、季军。选手名和比分随时可改，改掉旧比分，后面的对位会自动重算。

卡组页给每位选手两个卡组位，每个卡组最多放两张 16:9 图片。点图片放大，添加图片可以点上传，也可以把文件拖进添加框，传好的图能随时更换或删除。

## 本地运行

前端是纯 HTML/CSS/JS，不需要构建工具。启动：

```bash
npm start
```

默认地址是 http://localhost:8000，也可以用 `PORT=3000 npm start` 或 `node server.js 3000` 换端口。

## 数据怎么存

数据默认存在浏览器本地（IndexedDB），刷新和重启不会丢。部署到 Vercel 后，站点通过 `api/` 下的接口把比赛数据和图片存到 Vercel Blob，任何设备打开网址看到的都是同一份内容。访问者只能看，主办方在设置里输入管理口令后才能编辑。

## 测试

```bash
npm test
```

测试覆盖双败赛制的场次结构、胜者与败者流向、待定对位、比分合法性和冠军判定。
