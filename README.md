# 8 人 BO3 双败淘汰赛制网站

零依赖、可重复使用的赛事展示网站，包含两个页面：

- **赛程页**（`index.html`）：8 人标准双败淘汰赛（BO3，无总决赛加赛，共 14 场）。胜者组 R1(4)→R2(2)→决赛(1)，败者组 R1(2)→R2(2)→半决赛(1)→决赛(1)，胜者组决赛败者进入败者组决赛；总决赛结束后显示冠军、亚军、季军。可填写选手名称与比分，胜者自动晋级、败者自动落入败者组；修改任意旧比分都会自动重算后续对位；赛制规则显示在可收起侧边栏。
- **卡组页**（`decks.html`）：每位选手两套卡组，每套最多两张 16:9 图片；点击图片可放大查看，支持点击上传、直接拖入图片添加、更换与删除。

## 使用

```bash
npm start
```

默认访问 <http://localhost:8000>（可用 `PORT=3000 npm start` 或 `node server.js 3000` 修改端口）。

## 功能说明

- 顶部导航可在「赛程 / 卡组」两页间切换；右上角可选择、新建、重命名、删除比赛。
- 「设置」可修改当前比赛的名称、赛制规则与背景图片；背景图上传后自动压缩至最长边 1920px；云端模式下还需在此输入管理口令解锁编辑。
- 卡组图片仅支持本地上传，自动压缩至最长边 1600px，与赛事数据一起保存在浏览器 IndexedDB 中，刷新或重启页面不会丢失。
- 赛程页「重置比分」只清空比分，保留选手与卡组。

## 数据存储

本地运行时数据保存在浏览器（IndexedDB + localStorage）。部署到 Vercel 后自动进入云端模式：赛事数据存为 Vercel Blob 中的 `data.json`，图片存为独立 Blob 文件；任何设备打开网址都能看到同一份数据，访问者只读，主办方凭管理口令编辑。本地开发或离线时自动回退到浏览器本地模式。

## 上线（Vercel）

1. 注册/登录 Vercel，创建一个 Blob Store，复制它的读写 Token。
2. 在 Vercel 项目环境变量中配置两项：
   - `BLOB_READ_WRITE_TOKEN`：Blob Store 的读写 Token；
   - `ADMIN_TOKEN`：自定义管理口令（用于解锁编辑）。
3. 部署本项目：在项目目录运行 `npx vercel`（按提示登录并部署），或在 Vercel 网页中拖拽上传项目文件夹。
4. 打开部署后的网址 → 右上角「设置」→ 输入管理口令并「解锁」→ 如需保留本机已有数据，点击「将本机数据上传到云端」。

说明：首次访问未配置 `ADMIN_TOKEN` / `BLOB_READ_WRITE_TOKEN` 时，页面会自动退回本地模式。

## 测试

```bash
npm test
```

测试覆盖双败赛制拓扑、胜者/败者流向、待定对位、比分合法性、修改比分后下游重算与冠军判定。
