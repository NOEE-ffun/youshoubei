# 右手杯——8 人 BO3 双败淘汰赛制网站

这个网站服务一场 8 人卡牌比赛,如今是一个功能完整的小型 web 应用:办赛、看赛、归档、做海报都在浏览器里完成。部署后数据存云端,任何设备打开网址看到同一份内容;访客只能看,主办方在设置里输入管理口令后才能编辑。

打开网站先到主页:选手跑马灯加比赛背景幻灯,不放比赛数据,只当门面。页头导航通往四个功能板块。

## 比赛(schedule.html)

主办方的工作台。赛程按标准双败淘汰赛排布,一共 14 场:胜者组四分之一决赛四场、半决赛两场、决赛一场;败者组第一轮两场、第二轮两场、半决赛一场、决赛一场,最后是总决赛。胜者组决赛的败者进入败者组决赛。胜者组决赛、败者组决赛和总决赛采用 BO5,其余对局为 BO3。

整个赛程铺在一张画布上,对局卡片可以拖拽摆放,Ctrl/⌘+滚轮缩放,也可以切换成滚轮直接缩放的模式;卡片之间有曲线标出胜者组和败者组的晋级流向。填完比分,晋级名单和最终名次自动更新,不需要手动安排下一轮;改掉旧比分,后面的对位也会自动重算。总决赛结束后显示冠军、亚军、季军。

每张对局卡片上有"查看卡组"按钮,点开是这一局双方的卡组:BO3 每名选手两套,BO5 三套,每套最多放两张 16:9 图片。图片可以点上传,也可以把文件拖进添加框,传好的图能随时更换或删除,点开有灯箱放大。同一选手在不同对局里的卡组互相独立。

## 选手库(players.html)

管理跨届通用的全局选手:名字、头像、赛前垃圾话、专属颜色。垃圾话和颜色会跟着选手进海报,颜色决定海报里那一侧的视觉基调。删除选手不影响历史比赛记录,过去的对局里该选手显示为"待定"。头像上传前会自动压缩。

## 比赛库(library.html)

赛后的档案馆,只读。页面顶部下拉按届切换,画布沿用赛程页的摆放,对局卡片带着 BO3/BO5、已结束、平局这些状态和晋级流向线,方便回看整届比赛怎么打的。点"查看卡组"以只读模式打开当场的卡组图片。

## 海报生成器(poster.html)

赛前做 VS 海报。左右选手从主站选手库选取,名字、头像、颜色、垃圾话一并带过来,也能临时改;每侧可以放一张队标图片并调整大小,内置多套主题。预览和导出共用同一份 SVG,所见即所得,可导出 1080p/2K/4K 的 PNG。还有一个"生成 OBS 源"按钮:调服务器接口生成一个短链地址,复制粘贴到 OBS 的浏览器来源,直播时就能展示这张海报,链接 7 天有效。

## 本地运行

前端是纯 HTML/CSS/JS,不需要构建工具。启动:

```bash
npm start
```

默认地址是 http://localhost:8000,也可以用 `PORT=3000 npm start` 或 `node server.js 3000` 换端口。

## 数据怎么存

数据默认存在浏览器本地(IndexedDB),刷新和重启不会丢。部署后,`server.js` 同时提供静态站点和 `api/` 接口,比赛数据写入阿里云 OSS 的 `data.json`、图片写入 OSS `images/`,任何设备打开网址看到的都是同一份内容。管理口令只存 sessionStorage,关掉标签页就清掉。图片上传以文件魔数校验类型(PNG/JPEG/WebP/GIF),不信任客户端声明。阿里云 ECS 部署步骤见 [`deploy/README.md`](deploy/README.md)。

## 代码结构

- `bracket-model.js`:赛制纯逻辑(对阵解析、比分合法性、名次派生),浏览器/Node 双端可用,有单元测试
- `canvas-model.js`:赛程画布的数据模型(卡片坐标、晋级流向解析),比赛页与比赛库共用
- `common.js`:存储层(IndexedDB/云端适配)、页头/弹窗/灯箱/toast 提示,跨文件共享工具(`window.TournamentUtils`)
- `bracket.js` + `canvas-editor.js`:比赛页渲染与画布交互(卡片拖拽、滚轮缩放)
- `deck-modal.js`:卡组弹窗,编辑与只读两种模式
- `home.js`:主页跑马灯与幻灯
- `players.js` / `library.js`:选手库、比赛库页面逻辑
- `vs-poster/`:海报生成器(状态管理、表单、SVG 生成、PNG 导出、OBS 舞台)
- `server.js`:静态站点 + `/api/*` 一体化服务(原 Vercel Serverless 适配到 Node 进程)
- `api/`:健康检查、读写 OSS data.json、图片上传、OBS 舞台一次性生成(`/api/poster-stage`,管理口令 POST 创建 / 公开 GET 读取,7 天过期)

## 测试

```bash
npm test
```

测试覆盖双败赛制的场次结构、BO3/BO5 比分合法性、胜者与败者流向、待定对位、对局卡组迁移、选手字段归一化、画布模型和服务冒烟。
