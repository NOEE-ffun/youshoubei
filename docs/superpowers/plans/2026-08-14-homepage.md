# 主页面（品牌门户）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增纯品牌极简主页面作为站点首页:流体渐变背景 + 线稿右手(食指中指夹卡牌)主视觉 + 大标题 + 进入赛程按钮;赛程页改名为 schedule.html,导航提供「主页 · 赛程」切换。

**Architecture:** 新 `index.html` 为纯静态主页(零 JS,不加载 common.js);原赛程页整体改名为 `schedule.html`(内容不变);`common.js` 的 `renderHeader` 导航改为两项,`bracket.js` 的 `activePage` 改为 'schedule';主页样式追加到 `styles.css` 的 `.home-*` 段。

**Tech Stack:** 原生 HTML/CSS/SVG(手形线稿用内联 SVG 绘制,`stroke-dasharray` 动画实现描边流动),零新依赖。

## Global Constraints

- 主页零 JS:不引入任何 `<script>`,不加载 common.js/bracket.js/deck-modal.js
- 主页不含任何比赛数据(选手名、比分、管理入口)
- 不引入新依赖、不引入外部图片/字体资源(手形 SVG 内联绘制)
- 代码风格:语义化 HTML、中文注释;样式变量复用现有 `:root` 令牌
- `prefers-reduced-motion: reduce` 时停用主页全部动画
- 每次任务结束提交一次(中文提交信息),两目录(`youshoubei-dev`/`tournament-site`)文件保持字节一致
