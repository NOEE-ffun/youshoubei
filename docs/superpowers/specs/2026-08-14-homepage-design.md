# 主页面(品牌门户)设计

日期:2026-08-14
状态:已获用户批准

## 背景

当前 `index.html` 直接是赛程页,页头品牌文字「赛制面板」无跳转。用户希望新增一个**不包含任何具体比赛信息的主页面**作为站点首页,视觉上"艺术有多艺术,好看第一"。

## 页面架构

| 文件 | 角色 |
|---|---|
| `index.html`(新建) | 主页,站点首页:纯静态 HTML + CSS,零 JS 依赖,不加载 common.js/数据层 |
| `schedule.html`(由现 index.html 改名) | 赛程页,内容不变,调整 `<title>` 与导航高亮 |
| `styles.css` | 追加主页样式段(保持单文件模式,零新依赖) |

导航改造(`common.js` 的 `renderHeader`):
- 页头导航从单一「赛程」链接改为「主页 · 赛程」两项(`data-page="home"` / `data-page="schedule"`)
- 品牌文字「赛制面板」改为指向主页的链接
- 主页自身不渲染页头(它是独立全屏艺术页,仅含「进入赛程」按钮与角标返回能力?——主页是纯静态,不加载 common.js,所以主页没有页头,只有一个进入赛程按钮)

## 主页视觉

### 背景
- 流体渐变:多层大尺寸径向/锥形渐变光斑(蓝紫 / 品红 / 青色系),`filter: blur` 后以约 12s 循环缓慢平移/旋转,如液态颜料流动
- 叠加极细噪点/网格质感(内联 SVG data-URI 或 CSS 图案)

### 主视觉图形:线稿右手夹卡牌
- 一幅大型线条描边 SVG(约 500px),白色细描边(约 1.5-2px)、半透明,置于标题后方
- 构图:右手从画面下方伸入,**食指与中指夹住一张微微倾斜的卡牌**;卡牌为圆角矩形 + 内框线(两层描边表达卡牌轮廓),其余手指自然弯曲
- 描边带「绘制流动」动画(`stroke-dasharray` 循环推进),如墨水不断描画;图形整体轻微悬浮浮动

### 主体层次
- 大标题「赛制面板」约 96px 白色,置于图形前方(图形半透明,保证可读)
- 小号氛围英文装饰字(如 `TOURNAMENT · ARENA`)
- 毛玻璃「进入赛程」按钮(延续 `--surface-glass` 半透明风格,白色描边,hover 光晕),点击跳转 `schedule.html`

### 动效与无障碍
- 标题入场:淡入 + 上浮(约 600ms)
- `prefers-reduced-motion: reduce` 时停用全部动画(流动、描边、入场)

## 兼容与验证

- 所有指向 `index.html` 的引用更新为 `schedule.html`(`renderHeader`、README 等)
- 主页零 JS,无数据读取,任何浏览器完整显示
- 浏览器实测:主页视觉渲染、描边流动动画、「进入赛程」跳转、赛程页导航回主页
- 两目录(`youshoubei-dev` / `tournament-site`)字节同步
- 现有测试(11 组)不受影响(纯前端展示页)

## 范围外(YAGNI)

- 不做:主页多语言、主页管理入口、动态内容、卡牌翻转交互
- 手部图形为静态线稿 SVG,不做骨骼/手势动画
